# PNMSCA

PyTorch reimplementation of **Positive and Negative Multi-Scale Cross-Attention (PNMSCA)** from:

> Maryam Imani, Sergio Escalera. *Multi-scale cross-attention for multi-class imbalanced image classification*. Array, 2026.  
> [https://doi.org/10.1016/j.array.2026.101336](https://doi.org/10.1016/j.array.2026.101336)

All code lives in **`PNMSCA.ipynb`**

## Implementation was fully done through Google Colab
